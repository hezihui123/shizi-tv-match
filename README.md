# 🎈 识字消消乐 TV 版

一款专为**智能电视 / 电视盒子**设计的儿童识字与 K12 学习游戏，用遥控器即可操作。原版为「听音找字」消消乐，本仓库在此基础上扩展了完整的 K12 题库答题模式。

> 📢 **关注公众号：盒子汇** —— 获取更多 TV 应用、使用教程与持续更新。

---

## ✨ 功能特性

### 8 种原有玩法
数字、字母、汉字、数学、英语、拼音、常识等模式，配合 2928 条语音素材，听音找字、两两消除。

### 📚 K12 题库模式（新增）
- **5735 道**四选一题，全部带答案解析
- 覆盖 **5 个学科**：数学 2257 / 英语 1983 / 语文 1070 / 物理 314 / 科学 111
- 覆盖 **1–9 年级**，上册 / 下册 / 全学年三种学期
- 按 **学科 / 年级 / 学期** 三档筛选，筛选题数不足时自动逐级放宽
- 题干支持系统 TTS 朗读（英语用英文发音）
- 答完题自动朗读「正确答案 + 解析」，可点「🔊 听解析」重听
- 答题反馈用整屏浮层完整展示解析，不再截断
- 抽题优先出错题与久未复习题；学习档案按学科统计掌握情况

### 📺 TV 适配
- 固定 1920×1080 画布等比缩放，适配不同电视分辨率，考虑 overscan 安全边
- 遥控器焦点高亮：未选中项聚焦有橙色背景，选中项保持深蓝高亮，一目了然
- 右下角提供「缩小 / 放大画面」按钮，个别电视可现场微调，设置自动记忆
- 大字号、大按钮，适合远距离观看

## 📦 安装包

直接下载仓库中的 [`识字消消乐+TV-语音解析版.apk`](./识字消消乐+TV-语音解析版.apk)（约 21 MB），拷贝到电视/盒子安装即可。

- 需要安卓 5.0（API 21）及以上
- 用 U 盘、文件互传工具或 adb 安装均可
- **若设备已安装旧版本，请先卸载再安装**（签名与原厂版本不同）

## 🗂 源码结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构，主界面 + 题库模式 + 答题浮层 |
| `styles.css` | 样式，TV 焦点态、筛选栏、浮层布局 |
| `app.js` | 游戏主逻辑：8 种玩法、K12 答题引擎、TTS、遥控器导航 |
| `data.js` | 基础字库数据 |
| `packs.js` | 各模式题目包配置 |
| `k12bank.js` | K12 题库数据（紧凑数组格式） |

> 这是一个 WebView 壳应用：网页资源放在 `assets/`，由原生 WebView 加载。本仓库同步的是网页源码与发布安装包；原生壳为编译产物（dex/arsc），未纳入版本管理。
